# DOTV 无限画布

一块画布：剧本、分镜、图片、视频、配音，一路做到成片。这个插件让 agent 够得着它。

## agent 能做什么

- **读画布** —— 列出你账号下的画布，再列其中一块画布上的节点：类型、状态、文本或提示词的
  一截、位置。
- **加节点** —— 在画布上放一个文本节点（先是草稿状态）。
- **跑生成** —— 跑一个节点，或者把一个组里待跑的节点一起跑掉。视频会先回一个还在跑的任务
  id，再读一次画布就知道它落到哪儿了。

## 你需要什么

- 一个 DOTV 账号 —— <https://dotv.ai>。
- 一份凭据。这台机器上跑过 `dotv login` 的话，插件就沿用那个登录态；否则在插件配置里填
  API key。
- 一块要动的画布。把画布 id 告诉 agent，或者在配置里定一块，画布就固定在它上面。

## 几点说明

- 跑生成消耗账号积分，跟在应用里做一样。
- 画布本身不在 harness 里渲染 —— 想看着它干活，在浏览器里开着 DOTV。
